> dataset used : https://www.kaggle.com/datasets/devendra416/ddos-datasets
> Both balanced.csv and unbalanced.csv datasets are available on the website.
> rename the respective files to "balanced.csv" and "unbalanced.csv" as they might have a different name and having these names is necessary for the model to work. Save the files in the same folder as the model for it to work.
